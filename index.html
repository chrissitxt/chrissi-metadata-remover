removing metadata
just drop your files in, or click to browse. everything is read directly in your browser, nothing gets uploaded to a server or processed anywhere else. metadata is stripped: camera info, gps location, and timestamps are removed, while the actual image content stays byte-for-byte untouched. each cleaned file downloads individually as soon as it's done.

right now this only supports jpeg, png, and webp images, up to 8 files at a time, 100mb each.
fair question, since everything runs locally there's no server cost or bandwidth to protect. the limit is about the browser itself, not about permission. every file gets held fully in memory as raw bytes while it's processed, so a large batch of huge files can genuinely slow a phone or an older laptop down. 8 files and 100mb each is just a comfortable ceiling that keeps things fast and predictable, not a hard technical wall.
