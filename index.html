chrissi's metadata remover

Removing metadata

Just drop your files in, or click to browse. Everything is read directly in your browser, nothing gets uploaded to a server or processed anywhere else. Metadata is stripped: camera info, GPS location, timestamps and everything else stored alongside the image are removed, while the image itself stays exactly the same. Each cleaned file downloads individually as soon as it's done.

Right now this only supports JPEG, PNG and WebP images, up to 8 files at a time, 100 MB each.

Everything runs locally, so there's no server cost or bandwidth to protect. The limit is about the browser itself. Every file has to be fully loaded into your browser while it's cleaned, so a large batch of huge files can genuinely slow older devices down. 8 files and 100 MB each is just a comfortable ceiling that keeps things fast and predictable, not a hard technical wall.
